SHUN TRACK iPhone ホーム画面アプリ版

1. このフォルダのファイルをまとめて HTTPS の静的サイト（GitHub Pages / Netlify 等）に公開します。
2. iPhoneのSafariで公開URLを開きます。
3. 共有ボタン→「ホーム画面に追加」→「追加」。
4. SHUN TRACKのアイコンから起動できます。

注意: このファイルをChatGPT内で開くだけではホーム画面アプリ化できません。公開URLが必要です。
保存は端末内のブラウザストレージです。Safariとホーム画面版でデータが共有されない場合があります。バックアップを活用してください。
